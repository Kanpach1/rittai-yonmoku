朱 R1〜R3 × 象牙 I1〜I3 の9組から1組を選んで比べる(色は16進数どおりの見た目になるよう変換済み)。背景 #0C1116・胡桃 #493229・黒鉄 #202528。
状態比較: 上が朱・下が象牙、左から Normal・Impact・Active。
Sparse / Midgame / Dense は、重力ルールに沿って朱から交互に指した固定の棋譜を再生した局面(途中で四目はできない)。Midgame と Dense は最後の一手で四目が完成し、その4球を Active にする(どちらの色で終わるか切り替え可)。
Adversarial は見分けにくさを意図して作った人工の配置(合法局面ではない): 朱を光の当たらない奥・低い段・柱の陰・木の縁に、象牙を手前の高い段の光の当たる側に置く。
核と微細構造は両色共通の銀白。Active は 0 で核が生まれ始め、約0.2で核が立ち、0.25〜0.9 で微細構造が浮かぶ(200ms 再生なら 核 0ms → 構造 50ms〜 → 完全活性 約180ms)。
